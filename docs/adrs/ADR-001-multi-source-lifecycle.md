# ADR-001: 輸入源混合容錯與 BD 階段生命週期模型

* **狀態**：Accepted
* **背景**：用戶在 POE2 國際服中接收到的 BD 資訊來源多樣（博主散文筆記、影片字幕文本、貼吧/論壇圖文、poe.ninja 角色頁快照等），且不同 BD 在遊戲中的定位截然不同（開荒型、搬磚過渡型、後期成型攻堅型）。若按單一死板模板處理，極易導致信息失真或在缺項時產生誤導。
* **決策**：
  1. **多源輸入與缺項顯式標註**：全面相容各類碎片化內容。若源資訊缺失關鍵維度（如缺少開荒指引、抗性配平建議），文檔在對應章節明確打上 `[⚠️ 原文未提及 / 補全建議]`，絕不偽造非事實數據。
  2. **生命週期顯式分級 (Lifecycle Classification)**：所有生成的標準規範文檔必須在文首強制標明【BD 定位分級】（`[開荒專屬]`、`[開荒轉搬磚]`、`[終局攻堅]`）。
* **後果**：杜絕新手拿著後期昂貴 BD 當開荒打導致卡關；對信息不全的源內容具備高度魯棒性與誠實性。

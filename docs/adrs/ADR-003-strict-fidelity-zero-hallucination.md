# ADR-003: 嚴謹保真與非臆測原則 (Strict Fidelity & Zero Guesswork)

* **狀態**：Accepted (Enhanced)
* **背景**：《流放之路 2》數值模型精密且玩法機制與初代差異極大（如精魂限制、武器專精天賦、架勢擊破條等）。若 AI 根據「通用經驗」隨意腦補操作手法、數值閾值或技能配置，極易造成 BD 徹底無法運轉或誤導玩家。
* **決策**：
  1. **條件性收錄原則 (Conditional Inclusion)**：操作連招/手法僅在博主原文/源數據中明確提及時才進行標準化提煉排版；若源內容未提及，嚴禁自行捏造連招，直接標註 `[⚠️ 原文未註明具體操作手法]`。
  2. **防禦與避坑指標真實性**：生存指標與避坑線僅在源數據明確指定時呈現，不強行套用通用的刻板數值模板。
  3. **機制白話解釋邊界**：僅對原作者提到的邏輯做白話因果鏈解構（觸發源 $\to$ 介質 $\to$ 承傷 $\to$ 風險），禁止未經證實的二次機制衍生推導。
* **後果**：杜绝 AI 幻覺，確保文檔 100% 忠實於作者思路，高度可信。

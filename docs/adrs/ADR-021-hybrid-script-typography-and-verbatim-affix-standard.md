# ADR-021: 简繁混合排版（麻花文）层级规范、词缀官方繁中原文与零黑话策略

* **Status**: Accepted (2026-11-01)

为了确保玩家在对照国际服繁体客户端与 `poe2db.tw` 时达到 100% 视觉零误差（尤其是帮助新手区分高度相似的装备词条），同时兼顾日常阅读与本地文件搜索体验，本项目的文本语言与排版边界执行以下规范：

1. **正文的简繁双轨（麻花文）与视觉加粗层级**：
   - **叙事引导语 (Narrative Prose)**：连接词、操作手法、走线方位等非游戏名词统一使用**简体中文**。
   - **专有实体 (Proper Entity)**：職業、昇華名、技能/輔助寶石、裝備基底/傳奇、天賦節點名、NPC、通貨與符文统一使用**加粗官方繁中 `**官方繁中**`**，全面废除 `【】` 括号。
   - **系统机制词 (System Term)**：通用游戏系统与属性词（如 `天賦`、`昇華`、`精魂`、`盛怒`、`護甲`、`閃避`、`能量護盾`、`抗性`、`暴擊`、`擊暈`、`詞綴`、`插槽`、`異界`）统一使用**不加粗的官方繁中**，避免满屏加粗淹没核心实体。
2. **装备词缀强制使用官方繁中原文模板 (Verbatim Affix Text)**：
   - 废除“物理点伤”、“攻速”等简体概括写法，配装表中的词缀必须严格采用 `poe2db.tw` 官方繁中词缀原文模板（如 `附加 # 至 # 物理傷害`、`增加 #% 攻擊速度`、`+# 最大生命`）配对官方英文 Trade 筛选词。
3. **正文与表格 100% 清零攻略黑话 (Zero Slang Retention)**：
   - 技能连线表与配装表中彻底移除“攻略俗称”列及括号俗称（如 `/ 散弹`），仅保留「官方繁中 + 官方英文」。
   - 仅在对话式即时问答（模式一）的首行允许做一次「提问词 ➔ 官方繁中正名」映射确认，下方解析与表格全面禁用黑话。
4. **检索标题保持简体中文 (Searchable Header Exemption)**：
   - 本地文件名、文档 H1 大标题及 YAML `title` 字段保持简体中文，确保用户在 macOS 与 Notion 中使用简体输入法能直接搜到对应文档。

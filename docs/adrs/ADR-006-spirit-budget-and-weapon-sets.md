# ADR-006: 精魂預算保真與雙武器套組呈現邊界

* **狀態**：Accepted
* **背景**：
  1. 《流放之路 2》引入了全新的「精魂 (Spirit)」系統，永久光環、戰旗、常駐召喚物與部分觸發輔助均改為佔用精魂（基礎預算通常為 100，可透過權杖、盾牌、裝備詞綴或天賦擴展）。精魂稍有偏差，玩家就會出現核心光環開不出、召喚物召喚不了的致命問題。
  2. POE2 具備副手武器（武器套組 I 與武器套組 II）即時自動切換機制，甚至允許為兩個套組分別配置專屬天賦點。但部分 BD 純粹使用單套武器。
* **決策**：
  1. **精魂預算嚴格依原文，絕不無中生有**：
     - 若原文/源文檔中列出了具體精魂上限、光環佔用與剩餘數值，則完整標準化提煉為【精魂預算平衡表】。
     - 若原文未提及具體精魂計算或數值不明，**嚴禁自行推算或編造數值**，必須在技能光環章節明確標註：`[⚠️ 原文未註明精魂具體數值與分配，請依角色實際精魂上限微調]`。
  2. **雙武器套組條件性呈現**：
     - 只有在原作者明確提及雙武器切換、武器套組 I/II 技能綁定或武器專精天賦時，文檔才展開【雙武器套組配置】小節。
     - 原文若未提及雙武器切換，則**完全不主動添加**該模塊，保持簡練保真。
* **後果**：杜絕精魂數值誤導，避免玩家因數值計算失真而無法運轉 BD；保持雙武器邏輯的嚴謹與克制。

# ADR-016: 圖文交織時序提取、截圖即第一數據源與自動化驗收防線

* **狀態**：Accepted (Extends ADR-003, ADR-014, and ADR-015)
* **背景**：
  在標準化《0.5.5 古灵旋风地炼》文檔過程中，用戶敏銳反饋「總感覺少了點什麼」。深度審計後發現：
  1. **圖文時序割裂**：舊版 `scripts/read_docx.py` 僅提取純文字並批次解包圖片，文字與圖片之間的相對位置關係丟失，導致模型不知某圖片出現在何處。
  2. **正文未寫技能而截圖有**：PoE2 攻略作者常不寫技能文字，直接截取遊戲技能孔位。模型因未讀取截圖 Tooltip，退而求其次填寫了推測性通用輔助寶石（如「【輔助 1】」）。
  3. **隱藏機制與彩蛋遺失**：作者在截圖與隨筆中提及的天選之所電梯領天賦點、塗油卡技能槽、水晶化免疫藍寶石數量判定、夜臨腰帶 100% 臨界點等高價值實戰細節被過度概括而漏掉。
* **決策**：
  1. **升級 `scripts/read_docx.py` 支援圖文交織時序流 (Interleaved Flow)**：
     - 在遍歷 XML 段落 (`w:p`) 與表格單元格 (`w:tc`) 時，按文檔順序精確插入 `[IMG: imageX.png]` 標記。
     - 自動生成 `document_flow.txt`，使 AI 在閱讀文字時一併獲取相鄰的截圖編號。
  2. **確立「截圖即第一數據源 (Screenshots as Primary SSOT)」鐵律**：
     - 當原始文字缺乏技能連線時，嚴禁腦補或使用佔位符，必須強制逐字轉錄截圖中的寶石名稱、等級、品質、輔助數量與武器套組勾選狀態。
  3. **建立隱藏機制與黑科技提取清單 (Quirks & Exploits Checklist)**：
     - 強制提取跑圖領點、首飾卡技能、數值閾值（如怒火 5 的倍數、夜臨 100%）、淘寶技巧與底層防禦機制。
  4. **引入自動化驗收腳本 `scripts/verify_bd.py` (Automated Quality Gate)**：
     - 在標準化完成後必須自動執行驗收，檢查：
       - 孤兒圖片檢查（提取的圖片必須 100% 被 Markdown 引用）；
       - 佔位符檢查（禁止出現 `【輔助 1】`、`[待補充]` 等）；
       - 技能表格矩陣完整性；
       - Notion ZIP 平鋪封裝結構。
  5. **清理歷史沉澱 (Pruning)**：
     - 全面清除 `SKILL.md` 中廢棄的 Word (.docx) 生成描述，確保交付結構為純粹的 Markdown + Clean Notion ZIP。
  6. **全局 Skill 註冊**：
     - 將工作區軟連結至 `~/.agents/skills/poe2-bd-standardizer`，使技能在任何會話與路徑下均可被智能體自動發現與調用。
* **後果**：
  - 徹底根除技能寶石連線幻覺與佔位符問題。
  - 保證 100% 提取作者隱藏黑科技與實用細節。
  - 通過自動化腳本實現確定性的質量閉環。

# ADR-012: 外部連結 100% 完整保留、語義化歸位與純淨排版規範 (Link Preservation & Semantic Anchoring)

* **狀態**：Accepted
* **背景**：
  PoE2 BD 原始文檔中常包含多種高價值外部資源連結，如原作者主頁、實戰講解影片、遊戲內加點設定檔（`.build`）、POB 剪貼簿、配裝交易篩選等。
  在傳統摘要或自動化整理中，這些連結極易被誤判為宣傳廣告或口語廢話而被整段刪除，導致玩家無法下載加點檔、丟失網盤提取碼，或無法觀看一手教學影片。
* **決策**：
  1. **零丟失原則 (Zero Link Loss)**：
     凡原始文檔中出現的有效外鏈（作者社群、教學影片、網盤下載、POB/Pastebin、交易市集過濾等），必須 100% 完整收錄，嚴禁擅自省略。
  2. **結構化語義歸位 (Semantic Relocation)**：
     徹底清理作者散亂插入的口播碎碎念，依鏈接類型分流至標準化模組：
     - **作者與出處**：頂部元資料區以超連結自然錨定（例：`[作者名](URL)`）。
     - **教學影片**：頂部元資料區建立專屬超連結 `[教學影片名](URL)`。
     - **配套文件與配置下載**：在「配套加點檔導入指引」章節前置醒目標註，包含網盤連結與提取碼。
  3. **現代純淨排版標準 (Clean Typography)**：
     - 剔除「👈👈點擊直達」、「复制整段文字」等論壇與口播噪音符號。
     - 網盤提取碼統一使用單反引號包裹為行內代碼塊（如 `8EH9`），確保電腦/手機用戶雙擊即可一秒無誤複製。
  4. **失效風險防護標註 (Volatility Disclaimer)**：
     在第三方託管的網盤/配置下載區塊末尾，統一追加輕量防護提示（提示玩家失效時如何獲取最新版）。
* **後果**：
  文檔具備完整的資產可用性，玩家一鍵複製提取碼即可獲取遊戲加點檔，圖文與外鏈體系清晰專業。

# ADR-005: 圖像資產保留與結構化重定位 (Image Preservation & Semantic Relocation)

* **狀態**：Accepted
* **背景**：博主撰寫的 POE2 BD 文檔通常包含大量截圖（如天賦樹截圖、裝備詞綴圖、技能石連線圖、戰鬥面板等）。在進行標準化重組時，若丟失圖片會極大降低新手可讀性；但若維持博主原本混亂的插圖位置，又會破壞標準文檔的條理性。
* **決策**：
  1. **零丟失原則 (Zero Image Loss)**：凡源文檔中包含的有效圖片鏈接（Markdown 格式 `![alt](url)`、HTML 標籤或圖床鏈接），必須 100% 完整複製保留，嚴禁擅自省略。
  2. **語義對齊與順序重排 (Semantic Relocation)**：天賦圖歸入【二、啟動路徑與進階指南】，裝備/暗金/詞綴圖歸入【三、配裝與詞綴階梯指南】對應欄位下方，技能連線圖歸入【四、技能寶石連線配置】，面板截圖歸入對應機制或手法章節。
  3. **圖文互證與上下文註釋**：每張移動後的圖片均配合標準化文字描述，確保新手一眼看懂圖中展示的核心要點。
* **後果**：視覺直觀性 100% 保留，圖文結構高度契合規範文檔。

# ADR-008: 本地 Word (.docx) 文檔導出與離線圖片自包含打包

* **狀態**：Accepted
* **背景**：用戶需要將整理好的 BD 文檔在本地長期保存，且源文檔中包含大量教學圖片（天賦、裝備、寶石連線截圖）。若僅輸出普通 Markdown 或使用遠端圖床外鏈，一旦圖片原伺服器失效或離線閱讀時，Word 文檔將出現「紅叉破圖」；同時用戶希望獲得開箱即用、節省算力的輕量化 Word 格式。
* **決策**：
  1. **標準雙模本地交付 (Dual Local Artifacts)**：標準化轉換器同時生成兩份標準產物並存於本地專案的 `output/` 目錄：
     - 本地結構化 Markdown 文件（作為版本控制與文字基準）。
     - 本地自包含 Word 格式文件 (`.docx`)，自動下載源文檔中的圖片並將二進位資料直接嵌入 docx 內部（離線可讀，不依賴外部圖床鏈接）。
  2. **圖文無損搬運與排版自適應**：所有原圖以 100% 原始比例插入對應章節文字下方，自動按頁面可用寬度等比自適應縮放並居中排版。
  3. **極致輕量與算力節約**：採用純 Python 標準庫（或極簡轉換工具）實現 Markdown 與圖片向 OpenXML (.docx) 的封裝，不引入沉重依賴，毫秒級完成打包。
* **後果**：徹底解決圖片外鏈失效與跨平台排版失真問題，開箱即用，資源消耗極低。

# ADR-019: 战略转向实战 HUD 备忘单与 POE2 多维术语对齐中枢 (Strategic Pivot to HUD Cheatsheet & Rosetta Stone Alignment)

## 状态 (Status)
**已通过 (Accepted)** - 2026-09-25

## 背景与痛点复盘 (Context & Problem Statement)
在先前的版本演进中，项目逐渐演变成一个试图通吃所有第三方博主排版格式（语雀、Word、PDF、视频字幕）的富文本逆向重构引擎。这导致了严重的工程蔓延（Scope Creep）：
1. **格式适配是无底洞**：博主的自创格式与截图习惯千差万别，消耗大量算力在切图、去水印、解折叠和修复排版漏洞上，却脱离了玩家的核心诉求。
2. **真正的痛点是「四重翻译混杂与市集搜不出」**：
   - 玩家面对的是：**民间黑话（火雷/散弹/穿心弩） ⇄ 国服简中（爆炸榴弹/雇佣兵） ⇄ 官方繁中（爆炸擲彈/傭兵） ⇄ 官方英文 Trade 词（Explosive Grenade/Mercenary）** 的多重混杂。
   - 在游戏内 NPC 商人面前找不到技能，在官方 Trade 市集搜索 0 结果，导致抄作业体验极度痛苦。
3. **边玩边看需要极致精简**：玩家在双屏或手机上抄作业时，不需要阅读作者几万字的生活琐事，只需要一张**一屏看完、表格化呈现连线与核心数值的实战 HUD 备忘单**。

## 核心架构决策 (Decisions)

### 1. 语言与表达原则
* **日常交互与分析说明**：一律采用**简体中文**（对话、机制剖析、走线建议）。
* **游戏专有名词**：严格采用**【官方繁中】 (poe2db.tw 国际服唯一正名)** + **【官方英文】 (Path of Exile Trade 搜索词)** 双重标注。

### 2. 双核心运行模式
* **模式一：随问随查与黑话破译 (Instant Query & Rosetta Stone)**：
  - 用户输入任何简繁混杂或黑话句子；
  - 输出大白话机制解析 + 多维对照卡片（含技能连线表格、市集英文搜索词、商人购买章节）。
* **模式二：实战 HUD 备忘单 (HUD Cheat-Sheet Generation)**：
  - 彻底剥除所有废话，输出 5~10 KB 的超轻量单页 Markdown；
  - 包含四大模块：① 技能宝石连线与获取矩阵（强制表格）、② 官方市集淘装与基底速查表、③ 核心数值及格线表、④ 天赋步进路线与模拟器代码；
  - 深度支持 Notion MCP 一键直传。

### 3. 技能连线强制表格化 (Table-First Gem Matrix)
* 所有技能石与辅助宝石连线必须采用 Markdown 表格形式呈现：
  - 列定义：`主动技能 (官方繁中 / 英文)` | `插槽颜色/孔数` | `连线辅助宝石 (官方繁中 / 英文 / 攻略俗称)` | `开启/购买章节与 NPC` | `战斗手感与联动机制`。

### 4. 彻底清理旧资产
* 删除过时的重型脚本（Word/PDF 图片解包、嵌套 ZIP 打包），仓库与输出目录全面保持纯文本与零垃圾图片。

## 收益与影响 (Consequences)
* **用户体验**：无论面对多么混乱的攻略，都能在 3 秒内理清技能与装备的官方中英文名称，市集搜索与 NPC 购买零失误。
* **交付体积**：由原先数百兆图片压缩包降至 5~10 KB 单页纯文本，秒速同步至 Notion。
* **工程稳健度**：摆脱对不可控第三方文档排版的依赖，代码库与词库极度轻量稳定。

# ADR-004: 官方繁中術語校準與單一可信源 (poe2db.tw)

* **狀態**：Accepted (Updated)
* **背景**：《流放之路 2》存在國服簡體中文版本與國際服官方繁體中文版本。社群博主常混用國服簡中名詞、自創俗稱黑話，或使用「簡轉繁」外掛工具機械轉換文字（形成偽繁體），與國際服官方繁中翻譯嚴重脫節，導致玩家在遊戲內搜尋或交易行查價時完全匹配不到正確實體。
* **決策**：
  1. **全要素單一可信數據源 (Comprehensive SSOT)**：全面以 POE2 流亡編年史 (`poe2db.tw`) 作為一切遊戲實體（技能、輔助、暗金、基底、通貨、符文、精華、昇華、天賦、詞綴等）的官方繁中正名基準。
  2. **純淨正名與去黑話化 (Zero Slang Purification)**：輸出文檔中徹底淨化，一律只呈現官方繁中正名，杜絕博主個人俗稱、黑話或非標準稱謂。
  3. **術語消歧與糾錯過濾**：自動識別並攔截「國服名詞」與「簡轉繁偽繁體」，強制校準對齊為 poe2db 的國際服官方繁體中文規範名稱。
  4. **術語對照庫定位**：額外建立的術語對照字典僅供消歧輔助參考，隨版本平衡調整，一切以 poe2db.tw 即時最新資料為最終依據。
* **後果**：文檔純淨專業，徹底解決搜不到詞綴或買錯通貨、裝備、寶石的痛點。

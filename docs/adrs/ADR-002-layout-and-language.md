# ADR-002: 文檔結構組織模型與語言規範標準

* **狀態**：Accepted
* **背景**：用戶在 POE2 國際服遊玩，使用官方繁體中文客戶端及繁中交易行插件。同時，不同 BD 既需要統一的閱讀動線，又需要在面對純後期 BD 時動態聚焦轉型門檻與前置條件。
* **決策**：
  1. **統一自適應核心骨架**：保留【一、核心機制白話拆解】、【二、啟動路徑與進階指南】、【三、配裝與詞綴階梯指南】、【四、技能寶石連線配置】四大主幹板塊，並輔以【五、實戰操作與手法】與【六、防線與避坑清單】兩大條件性板塊。開荒 BD 詳述劇情過渡，後期 BD 動態聚焦前置暗金與轉型門檻。
  2. **全文檔語言標準：統一規範繁體中文 (Traditional Chinese)**：所有裝備名稱、技能石、輔助石、詞綴描述、昇華天賦、符文與通貨名稱均嚴格按照國際服官方繁體中文翻譯輸出。
* **後果**：徹底消除語言壁壘與交易搜索障礙，兼顧閱讀完整性與實用性。

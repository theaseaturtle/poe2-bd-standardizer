# ADR-009: 全局純淨排版（去符號化）與跨平台中文字體標準

* **狀態**：Accepted
* **背景**：
  1. 社群 BD 攻略歷史上大量充斥著 `【】`、`[]` 等方括號符號（貼吧論壇遺留風格）。在結構化表格與層級 Markdown 中，每個技能、裝備、詞綴都包裹 `【】` 會造成極其嚴重的視覺雜訊，降低現代文檔的可讀性。
  2. 用戶主要在 Mac (macOS) 環境下工作，文檔同時會在 Windows 或行動端打開。若在 OpenXML 中硬編碼微軟專有字體（如微軟正黑體），在 Mac 上會觸發系統強制替換，導致字距發散或回落為粗劣的宋體；若硬編碼 Mac 專有字體（蘋方），在 Windows 上又無法識別。
* **決策**：
  1. **全局深度去符號化 (Clean Typography)**：
     - 表格內部、配裝章節標題、詞綴優先級全面剔除 `【】` 符號。
     - 實體與關鍵詞一律採用標準 Markdown 加粗 (`**名稱**`) 或三級標題 (`### 部位`) 進行清晰自然的層級區隔。
     - 表格排版：首列「主動技能」加粗居中錨定視覺焦點，其餘「輔助寶石」靠左整齊排列，等級序號統一以輕量小括號標記（如 `多重射擊 (2級)`）。
  2. **跨平台無襯線字體棧與 OpenXML 字體表 (Cross-Platform Font Stack)**：
     - 在 `word/styles.xml` 與 `word/fontTable.xml` 中配置雙端智慧映射：
       - 東亞字型指定為現代無襯線黑體：優先以 `PingFang TC` (蘋方-繁) 為主，並透過 `altName` 映射至 Windows 系統的 `Microsoft JhengHei` (微軟正黑體)。
       - 西文字型與數字統一使用現代經典無襯線字型 `Calibri`。
     - 徹底杜絕跨平台字體缺失、缺字或生硬回落為宋體的問題。
* **後果**：排版極度清爽現代，無論在 Mac 還是 Windows 打開均呈現原生頂級黑體質感。
